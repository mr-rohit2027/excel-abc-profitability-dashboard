# ABS Executive Summary & Profitability Dashboard

## About the Project

I created this Excel dashboard to analyze sales performance, revenue, and profitability across different countries, regions, and sales channels.

The dashboard presents important business metrics in one place and allows users to explore the data using interactive slicers.

## Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Visualization

## Key Performance Indicators (KPIs)

- Total Revenue
- Total Gross Profit
- Gross Profit Margin
- Total Units Sold
- Total Orders
- Cost of Goods Sold (COGS)

## Dashboard Features

- Monthly revenue and gross profit trends
- Top 5 countries by revenue
- Revenue share by sales channel
- Regional performance comparison
- Country-wise revenue map
- Interactive filters for product category, country, and quarter

## Key Objectives

- Understand monthly sales and profit trends
- Compare revenue across countries and regions
- Identify the contribution of different sales channels
- Track important profitability metrics
- Make business performance easier to understand through visualizations

## Project File

The Excel workbook includes the dashboard, sales data, and Pivot Tables.

Download the `.xlsx` file from this repository to explore the dashboard and its interactive filters in Microsoft Excel.

## Conclusion

This project helped me practice Excel-based data analysis, business reporting, and dashboard creation. It demonstrates how sales data can be presented visually to support business decisions.
